# 05 · 数据服务（apigw）自研设计

> 为什么自研：数据中台语境的"数据服务"（SQL 模板化 → 带鉴权/限流/审计的 API）
> 没有对口开源单品（论证见 03 文档）。需求参考 magic-api / dbApi(Datavane) 的功能清单。

## 选型

```
FastAPI + SQLAlchemy(async) + sqlglot(SQL校验) + cachetools(结果缓存) + slowapi(限流)
网关能力(路由/鉴权/限流)全部在 FastAPI 代码内实现,APISIX 暂不引入（见 04 文档）
```

## 五张核心表

```sql
-- API 定义
CREATE TABLE ds_api (
    id            BIGINT PRIMARY KEY AUTO_INCREMENT,
    code          VARCHAR(64) NOT NULL UNIQUE,     -- API 编码(对外路径)
    name          VARCHAR(128) NOT NULL,
    datasource_id BIGINT NOT NULL,                 -- 指向 Doris 数据源
    sql_template  TEXT NOT NULL,                   -- 参数化 SQL 模板(:param 绑定)
    cache_ttl     INT DEFAULT 0,                   -- 结果缓存秒数,0=不缓存
    row_limit     INT DEFAULT 1000,                -- 单次最大行数
    timeout_ms    INT DEFAULT 5000,
    status        VARCHAR(16) DEFAULT 'draft',     -- draft/published/offline
    owner_id      BIGINT NOT NULL,
    created_at    DATETIME DEFAULT CURRENT_TIMESTAMP,
    updated_at    DATETIME DEFAULT CURRENT_TIMESTAMP ON UPDATE CURRENT_TIMESTAMP
);

-- API 参数
CREATE TABLE ds_api_param (
    id          BIGINT PRIMARY KEY AUTO_INCREMENT,
    api_id      BIGINT NOT NULL,
    name        VARCHAR(64) NOT NULL,
    type        VARCHAR(16) NOT NULL,              -- string/int/date...
    required    TINYINT DEFAULT 0,
    default_val VARCHAR(128),
    validation  VARCHAR(256),                      -- regex 或枚举
    UNIQUE KEY uk_api_param (api_id, name)
);

-- 应用凭证(AK/SK)
CREATE TABLE ds_api_app (
    id            BIGINT PRIMARY KEY AUTO_INCREMENT,
    app_name      VARCHAR(64) NOT NULL,
    app_key       VARCHAR(64) NOT NULL UNIQUE,
    app_secret    VARCHAR(128) NOT NULL,           -- 存 hash
    rate_limit    INT DEFAULT 10,                  -- QPS
    ip_whitelist  VARCHAR(512),
    status        VARCHAR(16) DEFAULT 'active'
);

-- 授权关系
CREATE TABLE ds_api_grant (
    id        BIGINT PRIMARY KEY AUTO_INCREMENT,
    app_id    BIGINT NOT NULL,
    api_id    BIGINT NOT NULL,
    expire_at DATETIME,
    UNIQUE KEY uk_app_api (app_id, api_id)
);

-- 调用审计
CREATE TABLE ds_api_log (
    id        BIGINT PRIMARY KEY AUTO_INCREMENT,
    api_id    BIGINT NOT NULL,
    app_id    BIGINT NOT NULL,
    params    JSON,
    cost_ms   INT,
    rows      INT,
    status    VARCHAR(16),                         -- ok/error
    ts        DATETIME DEFAULT CURRENT_TIMESTAMP,
    INDEX idx_ts (ts)
);
```

## 请求链路（8 步）

```
AK/SK 签名验证 → 查授权 → 限流计数(slowapi) → 参数校验
→ SQL 模板渲染(参数化绑定,防注入) → sqlglot 校验(禁 DDL/DML、强制 LIMIT)
→ 缓存查询(cachetools TTL+LRU) → 执行(超时熔断) → 审计落库(异步) → 返回 JSON
```

## FastAPI 骨架

```python
@router.post("/api/v1/query/{api_code}")
async def execute(api_code: str, req: QueryRequest, app: App = Depends(verify_app)):
    api = await get_api_with_grant(api_code, app.id)          # 定义 + 授权
    render = render_sql(api.sql_template, req.params)          # 参数化渲染
    validate_sql(render)                                       # sqlglot: 只读/LIMIT
    cache_key = f"{api_code}:{hash(str(req.params))}"
    if rows := await cache.get(cache_key):
        return rows
    rows = await doris.execute(render, timeout=api.timeout_ms, max_rows=api.row_limit)
    await cache.set(cache_key, rows, api.cache_ttl)
    await audit(api, app, req, rows)                           # 异步批量审计
    return rows
```

## 与其他模块的联动

1. **meta 模块**：API 发布后自动登记为"数据服务"资产，进入资产目录/地图
2. **ai 模块**：已发布的 API 注册为 Agent 的 MCP Tool——智能问数可直接复用已发布的 API，也便于外部系统（n8n/Dify）通过平台调用数据
3. **sched 模块**（可选）：API 定时预热缓存 = 一类调度任务

## 迭代备注

- 一期功能清单：模板 CRUD + AK/SK + 限流 + 审计 + 缓存（约 2-3 周）
- 二期可选：结果分页/游标、订阅推送、语义层（SuperSonic / Cube）按指标口径统一需求再评估
- 多实例化时：限流计数器迁 Redis、缓存迁 Redis，apigw 业务代码不动
