# AI-Native 大数据平台 · 设计记录

> **状态**：✅ 已交付（2026-11-04）。代码：`/Users/mac/Desktop/data-platform/`，测试 31/31 全绿。
> **一句话定位**：引擎层用成熟开源（不自研），平台层全自研，AI 对话作为横切交互层的大数据平台。

## 核心决策摘要（定稿）

| 决策项 | 结论 |
|---|---|
| 自研边界 | 引擎（Doris / Airflow / DataX / MySQL）不自研；平台层全自研；API 网关降级为平台内模块（apigw） |
| 技术栈 | FastAPI（模块化单体）+ MySQL + Doris + Airflow（LocalExecutor）+ DataX + Nginx |
| 砍掉 | Redis、APISIX（均有进程内替代 + 明确的加回触发条件，见 04 文档） |
| 核心交互 | AI 对话 = service 层第三个客户端；NL → 结构化配置 → 校验 → 草稿 → 人工确认 → 上线 |
| 红线 | AI 永远不直接上线任何任务，create 类工具只产草稿（HITL） |
| 模块 | 集成 / 开发 / 调度 / 资产 / 地图 / 服务 / 智能问数 —— 全部自研 |
| 备用方案 | 自研资产/地图若受阻，回退接 OpenMetadata（Apache 2.0，见 03 文档评估） |
